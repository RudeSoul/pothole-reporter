# AWS central service

This is the production shared service for the app. It is a single Node.js 22 Lambda
behind an API Gateway HTTP API, with on-demand DynamoDB tables for installations,
idempotency, usage caps, dedupe locks, potholes, spatial cells, tenders and aggregate
metrics. `GET /v1/map` and `GET /v1/impact` are intentionally public and return only an
allowlisted aggregate view. All write and vision routes require the installation
signature generated by the app.

Deploy from the repository root after authenticating the AWS CLI:

```bash
AWS_REGION=ap-south-1 infra/aws-central/deploy.sh
```

The script packages the service and generated LLM contract, uploads an immutable zip to
an account-scoped S3 bucket, and deploys `template.yaml`. It prints the native API
endpoint and detector secret ARN. Set the secret value (in the AWS console or with an
operator-controlled secret workflow) to:

```json
{"openai_api_key":"sk-..."}
```

The Lambda never receives that key as an environment variable. `openai_then_yolo` first
uses the shared OpenAI detector, then attempts the configured YOLO gateway only for the
documented exhaustion/fallback errors. Until an evaluated YOLO release is configured,
that second leg fails closed; the public map and tender/authority APIs remain available.

Use the CloudFormation `ApiUrl` output as the app's default `service_url`. Do not point
new releases at the retired Cloudflare Worker hostname.
